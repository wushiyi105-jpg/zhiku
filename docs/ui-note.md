# UI 说明：知库

- **谁在什么时刻打开**：给文档有多个版本的小团队。
- **首屏任务句**：这份资料，哪句能作数。
- **主操作**：按「登记来源版本 → 按段找依据 → 并排看冲突」推进；首屏先给输入和主按钮，结果区在下方或右侧。
- **主信息结构**：研究阅览桌；对比、时间线、原文与修订、队列或价签按任务选择，而不是通用卡片堆叠。
- **三种状态**：空状态指到第一步；已有内容显示结果、来源/计算依据和导出入口；失败或待确认时保留已填内容，并在原位置说明缺什么。
- **视觉原型**：研究阅览桌。底色、强调色、圆角、边框和数字字体都按该任务重定，遮住产品名后仍能从布局看出用途。
- **解释**：给文档有多个版本的小团队：回答按段锚定引用，旧版和新版冲突并排提示，缺依据时显示检索到什么、还应补哪份文档。
